# 译幕 0.4.1 · Opus 审校后的修复版

2026-10-05。通过本机 Mirasim 指定 `claude-opus-5-5[1m]`、high、平台路由进行只读审校；会话已完成，台账确认 `claude-opus-5-5` / relay / HTTP 200。主代理核实反馈、实施修改并验证，未升级 Astra。主代理的实际底层模型身份没有独立回执，不以默认配置作为证明。

## 更新内容

1. DOM 滚动字幕整理完成后保留已处理窗口，只把新增词提交给下一次整理，减少重复中文和重复调用。
2. 实时语义整理失败后停止自动发送；渲染与后续采音结果不会绕过暂停标志。YouTube 的 429 退避在跳转后继续生效，关闭再开启字幕仍可明确重试。
3. 跳转、换视频、刷新或关标签页时撤销旧字幕等待；多个网页共享请求时，只在全部等待者离开后中止 fetch。服务端跳过客户端已全部离开且尚未开始的排队翻译，不扣模型调用额度。已经开始的模型调用仍可能完成并消耗用量。
4. 只把停顿和引用类标点替换为空格，保留 `%`、`％`、负号、`/`、`#`、`&`、`@`、连字符与数字之间的冒号。`50%`、`-5°C`、`3:30`、`C#` 不再改变含义。
5. 纯标点译文与服务端校验保持一致，允许接收，显示为空，不再导致整批字幕暂停。
6. 通用网页字幕使用时间与正文生成稳定 id，前部或中间插入 cue 不会作废后面的已有译文。
7. 音频片段按当前视频倍速换算视频时间跨度，2 倍速时 7 秒采样按约 14 秒视频时间处理。
8. 启动器先核对正在运行的服务版本和配对码，发现旧版或其他目录服务时明确停止启动；补齐双击停止入口 `stop.cmd`。

## 升级

在旧安装目录打开 PowerShell，执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\stop.ps1`，再启动新版 `start.cmd`。新版也可双击 `stop.cmd` 停止服务。

本机同一安装目录保留原配对码和配置。在 Chrome / Edge 扩展管理页重新加载译幕，确认 **0.4.1**，再刷新视频页，无需重新配对。

## 验证及边界

- **173 项自动测试全部通过**，新增 16 项，覆盖滚动去重、停止重试、退避、共享取消、排队断开、符号、纯标点、稳定 id、倍速时间与启动版本检查。
- **8 项真实 MV3 浏览器集成检查通过**：扩展加载配对、跳转撤销与排队跳过、实际符号渲染、网页全屏、同 URL 刷新后实际翻译、DOM 新词提交、原生 TextTrack 插入及字幕开关。
- 浏览器运行实际 Chromium 和扩展、真实本地 HTTP 服务；视频网页与翻译后端为确定性夹具。本轮没有把夹具通过视作新的公网视频或云端语音验收。
- 音频时间仍是按片段长度与播放速率估算，不是逐词时间；采样中途改变倍速、冷加载本地 ASR 与繁忙队列的接近 5 分钟长请求仍需专项实测。
- 保留模型输出的 1.2 秒停顿和 12 秒合并上限校验，模型越界时仍明确失败，不静默放宽约束或重试。中文轨开启完整语句模式时仍会经过模型整理，这是现有行为，会消耗用量。
