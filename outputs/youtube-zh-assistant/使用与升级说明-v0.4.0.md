# 译幕 0.4.0：完整语句与自动延长显示

本机源文件及服务已更新。请在 Chrome / Edge 扩展管理页重新加载译幕，确认版本 **0.4.0**，再刷新视频页。既有配对与模型设置继续使用。

弹窗新增“完整语句显示”，默认开启。程序结合前后文，将同一句的相邻碎片整理为一条完整短句；长句按有意义的短语或分句呈现。关闭此项可恢复逐片显示。

## 停留时间

- 原字幕轨：从首片开始显示，到末片结束。例如 0–2、2–4、4–6 秒三个片段合成一句，就连续显示六秒。组内正文保持稳定。
- 下一句开始时切换，重叠区间按下一句起点裁切；不跨超过 1.2 秒的明显停顿，合并段最多 12 秒。
- 同一原始片段中包含多个句界时先拆分，再合并前后内容；没有逐词时间时按文字长度估算内部边界。
- DOM 与实时语音不能预知后文，会等待片段再整理。显示时长取语音跨度、至少两秒和中文阅读长度的较大值，上限十二秒，按顺序显示并标记延迟。连续说话或模型处理缓慢时会增加等待。

## 显示与限制

中英文按词换行，尽量避免最后一行只有一个字；停顿标点仍替换为空格。字幕拖拽、两行独立选色、正常同步提示隐藏继续有效。

保留来源顺序并验证每个输入片段恰好覆盖一次；时间由程序计算。识别漏词、无可用字幕、音频忙时丢片或语义边界不清时，仍不能保证每句完整。字幕轨预读通常优于实时 DOM / 语音。翻译失败保留原生字幕，关闭再开启字幕开关可明确重试。
