最终浏览器夹具使用模拟 HTTPS 页面、真实 HTML5 媒体与真实账号翻译，覆盖：逐站启用注册脚本，真实HTML5文字轨到实际账号中文翻译；位置、字号、透明度即时应用且保存，不改变翻译开关；通用字幕跳转、网页全屏及关闭后还原原生轨；停用网站清理浮层；重新启用只保留一份脚本（测试副本权限由必需声明保留）；授权复核拒绝时清理当前网页，重新启用仍可恢复；同数量字幕正文更新、轨移除和同地址媒体重置不会显示旧中文；开放Shadow DOM视频与自绘CC，中文生效时隐藏原字幕，关闭后原样恢复；并发位置、字号、开关补丁均保存成功，页面使用合并后的外观；DOM迟到译文有原句时间，字幕间隙清空中文并保留当前原字幕。夹具通过不代替公网平台通过。

## 权限、模型和范围

测试在独立 Edge Profile 加载逐轮扩展，预授列出的具体来源，未读用户日常浏览器 Cookie 或操作其登录配置；生产仍使用逐站 optional 权限，需要点击“在此网站启用”。Dailymotion/Khan 已知内嵌来源一起请求授权，注册脚本和后台消息校验限制到确认的播放器路径。[Chrome 官方文档](https://developer.chrome.com/docs/extensions/develop/concepts/match-patterns)说明 host permissions 的路径部分被忽略，因此不能声称浏览器授权只覆盖单条路径。

本机服务为 0.3.10，翻译继续使用已登录 Codex CLI 的 ChatGPT 账号路线，音频识别仍为本地 Qwen3-ASR。配置请求 gpt-6-luna / high / Fast；CLI 未返回可确认的实际模型与服务档位，不能把配置当作路由证明。字幕及识别原文仍送账号模型翻译。没有修改配对码和后端配置。无字幕网页的完整采音识别翻译链路、登录后课程、DRM/付费播放器及真实云端语音 API 未全面验收。

官方样本入口：[Dailymotion 字幕说明](https://faq.dailymotion.com/hc/en-us/articles/11206718122642-Watch-videos-with-subtitles)、[edX DemoX](https://support.edx.org/hc/en-us/articles/207205937-Is-there-a-walk-through-of-a-sample-course)、[Udemy 正常试看入口](https://support.udemy.com/hc/en-us/articles/229231027-How-to-preview-and-compare-courses)、[Coursera 首模块预览说明](https://blog.coursera.org/introducing-courseras-new-course-preview-experience/)。官方入口存在不证明本环境匿名可播。

## 升级与交付

完整包包含 verification/platform-five-rounds 的各轮自动测试、公网报告与截图及独立基线。发布包通过 RAR 真实解压逐文件 SHA256 与 ZIP 清单/哈希核验后删除 0.3.5 旧发布包，保留历史报告。用户日常 Chrome 仍需在 chrome://extensions 对原插件点击重新加载，确认 0.3.10，再刷新视频；本次独立浏览器成功不代表日常 Chrome 已重载。

主代理负责源码修复、测试、交付；两个 sol_worker（gpt-6.1-sol、high、标准速度）独立发现公开样本和课程访问边界，未调用 Astra。主代理模型身份以当前客户端为准。
