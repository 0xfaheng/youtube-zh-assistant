# 译幕 · 视频中文字幕助手

当前版本：**0.4.8**。

0.4.8（2026-10-10）新增醒目的第三方 API 配置板块，插件弹窗可以直接打开。接口地址、协议、模型和 API Key 集中填写，支持保存并启用、保存并测试连接、移除密钥。连接测试每次请求刚保存的服务，不读取字幕缓存。保留既有约 2 秒采音分片、识别与翻译并行、语义字幕及外观设置。

本版验证范围及限制见 [当前验证记录](VALIDATION.md)；详细改动和升级步骤见 [v0.4.8 开发记录](开发记录/v0.4.8.md)。第三方服务使用本机模拟接口验证，没有使用真实服务商账号实测。旧资料已移出正式源码与交付目录；批量物理删除被自动审批拦截，采用可逆归拢，保留本版必要证据与 Git 历史。

默认开启“完整语句显示”：结合前后文，将相邻碎片整理为完整短句或有意义的分句，再统一翻译。弹窗可以关闭该项，恢复逐片显示。句号后的下一句开头会单独参与后续合并；英文缩写和小数不会简单地按点号拆开。

合并后从首片开始时间显示到末片结束时间，期间不随原始碎片切换。例如三个片段分别覆盖 0–2、2–4、4–6 秒，合并句连续显示到第 6 秒。下一句开始时切换，重叠时间裁到下一句起点；不跨超过 1.2 秒的停顿，合并段不超过 12 秒。长句优先按完整短语分段。片段内部句界缺少逐词时间时按文本长度估算，精度低于原始逐词字幕。

DOM 字幕等待后文后整理，按语音跨度与文字阅读长度延长显示，依序呈现；低延迟采音识别后立即送译，完整语句模式利用已有上下文整理当前短句，不能预知还没说出的内容。连续说话、识别漏词或处理繁忙时仍可能不完整。中英文按词换行，尽量避免末行只剩一个字；显示时仍用空格代替停顿标点。当前验证见 [v0.4.8 开发记录](开发记录/v0.4.8.md)。

中文字幕和原文显示时，将逗号、句号、问号、引号、括号、省略号等停顿标点替换为空格，并合并重复空格。例如“你好，世界。”显示为“你好 世界”。小数点、英文单词中的撇号，以及百分比、负号、数字冒号和专名符号保留，例如 `50%`、`-5°C`、`3:30`、`C#`。字幕原始数据、翻译输入及同步时间不变。

在扩展弹窗“字幕外观”中点击“中文颜色”和“原文颜色”的色块，可独立选择任意文字颜色，预览与视频立即更新并自动保存。刷新或换视频继续使用；“恢复默认外观”会还原中文白色、原文浅灰色。

字幕浮层不显示运行状态文字。翻译尚未完成时保留原生字幕，失败时继续暂停自动请求；可关闭再开启中文字幕重试，也可在扩展弹窗检测本机服务。

字幕现在支持手动拖拽：按住中文或原文移动，松开后自动保存位置。位置按视频区域的比例保存，刷新、换视频和网页播放器全屏时继续使用；字幕会限制在视频区域内。弹窗显示“手动拖拽位置”，调字号和背景时保留坐标，选择顶部 / 底部或点击“恢复默认外观”可重置。此设置与原有外观一样，在已启用网站间共用。

本机已安装目录的源文件已更新。请在 Chrome 扩展管理页重新加载译幕，确认 **0.4.8**，再刷新视频页。无需重新配对；无字幕视频请重新点击“开始采音”。

0.3.10 的五平台历史测试补充 Dailymotion、Khan Academy、edX、Udemy、Coursera，各完成五次公网访问；该版 128 项自动测试和 9 项浏览器夹具通过。真实中文成功与登录/验证限制按平台记录，详见 `五平台五轮测试报告-v0.3.10.md` 和 `verification/platform-five-rounds/summary.json`。

新增多网站模式：除 YouTube 外，可在插件弹窗按站点启用 HTTPS 视频网站，读取 HTML5 原生字幕轨，兼容常见 Video.js / Plyr / Vimeo 页面字幕。TED 公共视频已完成真实中文显示验证，Vimeo 的字幕轨可读取但本次隔离浏览器起播未通过，暂列试验支持；Vimeo / TED 的已知跨域播放器会一起请求访问权限。没有可读字幕时，可手动开始本地语音识别 Beta。字幕文本仍交给当前账号或 API 翻译。

新增字幕外观：顶部 / 底部、距离边缘 0–70%、字号 14–48px、背景浓度 0–100%，实时应用并保存，可恢复默认。新图标和弹窗统一使用“译幕”品牌。已有配对码及本机设置继续保留。

本版修复真实 YouTube 字幕地址缺少播放器参数的问题。开启播放器 CC 后，扩展自动读取播放器实际请求的完整字幕，并在未来约 90 秒内按每批最多 20 条提前翻译。若字幕持续为空，约 20 秒后会打开 YouTube 原生“内容转文字”面板，尝试读取完整文字稿；此时时间精度低于原字幕。正常字幕恢复后优先使用原字幕。初次模型调用仍需等待，建议等中文出现后再播放；两种完整数据均不可用时保留 DOM 兜底。

这是一个在 Windows 本机运行的视频字幕翻译助手预览版，包含 Chrome/Edge 扩展和本地服务。扩展读取可用字幕，翻译为中文或中英双语并按时间同步；没有可用字幕时，可启用音频捕获 beta。

## 环境与启动

需要 Node.js 22+、Chrome/Edge 116+。这台电脑已有 Node.js 和 Codex CLI；账号模式需要有效登录，API 模式需要有效接口配置。运行时无需安装 npm 第三方依赖。

1. 完整解压安装包，双击 `start.cmd`，打开本机设置页。
2. 在 Chrome 地址栏打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。启用“开发者模式”，点“加载已解压的扩展程序”，选择解压目录中的 `extension` 文件夹。
3. 在安装插件的同一 Chrome/Edge 浏览器配置中打开本机设置页，点“一键配对浏览器插件”。必须显示插件版本及“配对已验证”。也可在弹窗手动保存配对码，新版会验证有效后才保存。
4. 在设置页选择翻译方式，点击“保存并测试当前翻译方式”。第三方 API 可从插件弹窗的“配置第三方 API”直达独立板块，填写后点击“保存并测试连接”。API 密钥只填在本机设置页。
5. 刷新已经打开的 YouTube 普通视频，打开插件面板，点击“启用译幕”。插件立即开启可用的播放器 CC，并读取字幕开始翻译；已有中文缓存立即显示，首次中文需等待翻译服务返回。点击“停用译幕”立即关闭原字幕和译文，并停止采音。没有字幕轨的视频仍需手动开始采音。浏览器重启或扩展重载后，需要再次手动启用。

首次通过启动器打开带 `#token=...` 的链接配对，页面随后移除地址中的配对片段。直接访问 `http://127.0.0.1:17865` 不会自动获取配对码；重新运行 `start.cmd` 或从已配对扩展点击“本机设置”即可。token 存于本机 `work` 运行目录，不在安装包中；请勿转发。

更新完整安装包时，在旧目录执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\stop.ps1`，再运行新版 start.cmd；新版也提供双击停止入口 stop.cmd。本次资料清理未重启本机服务。更新已有插件时，在扩展管理页点击重新加载，确认版本 0.4.8，再刷新视频网页。当前本机 Chrome 安装的是 `outputs/youtube-zh-assistant/extension`，重载该扩展后，打开插件面板点击“启用译幕”。保持同一个安装目录时，既有配对码和配置继续使用；本机服务只监听 `127.0.0.1`。

其他网站：打开 HTTPS 视频页，点击译幕图标，再点“授权此网站”。确认浏览器的具体站点权限后，点击“启用译幕”，开启网页播放器字幕并播放。字幕外观在弹窗中调整，顶部/底部位置按当前视频区域计算。撤销网站授权会移除注册脚本、清理浮层并撤销可撤销的站点权限。部分网页播放器使用自绘原字幕，可能继续显示原文；可关闭播放器自己的字幕显示或将译幕调至顶部。跨域播放器必须包含在明确授权的来源内，未知播放器需要在播放器的独立页面授权；不会自动获取所有网站权限。

## 翻译与模型配置

界面可选 `codex` 或 `api`。`codex` 复用本机 Codex CLI 的 ChatGPT 登录，默认请求 `gpt-6-luna`、`high`、Fast；如明确收到 Fast 不可用错误，可切回标准模式，不会静默换模型。成功样本证明本机账号路线能返回翻译，但 CLI 未返回实际模型或服务档位标识，不能据此保证实际路由。CLI 请求消耗 ChatGPT/Codex 用量。`api` 使用 OpenAI Responses API 或兼容的 Chat Completions API，默认 `gpt-4.1-mini`，API 单独计费。模型和后端可调整。

第三方 API 板块始终显示，无需先切换翻译方式。填写接口基础地址（Base URL）、协议、模型 ID 和 API Key；基础地址保留服务商要求的路径（例如 `/v1`），不要附加 `/chat/completions` 或 `/responses`。第三方服务按其文档选择 Chat Completions（需要 JSON 输出）或 Responses（需要 JSON Schema 输出）。远程接口使用 HTTPS，本机兼容服务可使用 HTTP。

“保存并启用 API”只更新翻译 API 配置和共用密钥，不会提交尚未保存的语音或账号字段；“保存并测试连接”先保存并启用 API，再发出一次实际翻译请求，可能产生费用。每次测试都请求服务，不读取字幕缓存；失败会显示鉴权、额度、地址或协议错误，不自动切换服务或重试。测试失败后，已保存的 API 配置仍生效，可修改后重试，或切回账号方式并保存。

密钥留空保留已有值且不改变保存方式；输入新密钥时，勾选加密保存使用 Windows DPAPI，取消勾选则只保留到服务退出。API 翻译和云端语音当前共用一个密钥，两个服务必须接受同一密钥；本机语音识别不受此限制。移除密钥会清除当前服务内存和本机加密文件，但若配置了环境变量，重启后会重新读取。页面只显示密钥状态，不回显密钥。

音频识别默认选择“本机 Qwen3-ASR”，无需语音 API 密钥。也可手动选择云端语音 API，默认 `gpt-4o-mini-transcribe`。API 密钥可填入本机界面或通过环境变量提供；Windows 使用 DPAPI 加密，仅同一用户和电脑可解密。不要把密钥发到聊天中。Codex 路径无需粘贴网页 Cookie。

这台电脑的本地模型在 `D:\AIModels\Qwen3-ASR-1.7B`，使用 WSL `Dayuanzong` 的 `/opt/dayuanzong/venvs/qwen/bin/python`。此安装包只包含接入代码，不包含模型和 Python 环境；换电脑需已有对应部署。本地识别失败时会报错，不自动上传云端。

## 开关的使用方法

1. 双击 `start.cmd` 启动本机字幕服务；已有配对无需重复配对。
2. 打开视频，点击插件图标，再点“启用译幕”。YouTube 可用的 CC 会立即开启；中文首次生成需要等待翻译，译文就绪前保留原字幕。实际等待时间受登录状态、网络和模型处理影响。
3. 点击“停用译幕”，当前已适配播放器的原字幕和译幕译文立即隐藏，正在处理的旧结果不会重新显示。再次启用恢复可用的字幕和缓存。
4. 若显示“当前视频页未响应”，刷新视频页；若提示翻译连接失败，启动本机服务或按提示检查配对。无字幕视频需手动开始采音。

初始默认停用不修改网站原字幕；用户主动点击停用后，在本次浏览器会话隐藏已适配的原字幕。其他网站仍需先授权，播放器自绘字幕的覆盖范围限于现有适配选择器；烧录在视频画面内的文字无法通过字幕开关隐藏。

## 使用字幕与音频 beta

字幕轨可用时，扩展读取完整字幕，提前约 90 秒批量翻译，再按视频时间显示。播放器实际请求包含的临时参数仅用于本视频字幕读取，不写入安装包。读取失败时退回页面 DOM 监听；翻译慢于视频时保留当前原字幕，同时在更高位置显示带时间标记的原句与中文。DOM 兜底可能漏句，不能保证完整同步。支持中文/双语；跳转或换视频会隔离旧请求，暂停后停止采音。当前真实浏览器验证范围见 VALIDATION.md。

无字幕时，在设置页“语音识别与调用额度”选择本机模型，保存后点“预热本地模型”。状态显示已就绪，再回到视频页，在扩展弹窗点击“启用译幕”和“开始采音”，保持视频播放即可，不需要逐句操作。首次加载需要等待；“释放本地显存”按钮可以主动卸载模型。

连续语音约2秒切片，跳过前导静音；片段已采集至少约0.8秒且出现约0.3秒停顿时提前提交。识别后立即送译，两种显示模式均不额外等待句号，下一片识别可与翻译并行。时间按实际片长与播放速度计算。识别繁忙时仍丢弃新音频，弹窗显示音频完成与跳过计数；慢翻译时保留最近约8秒待译文字、限制排队显示时长，过旧结果跳过，可能漏句，文字跳过不计入音频计数。字幕浮层只显示字幕。

一次合成英语首片测试使用真实本机识别与账号翻译，预热后从采集开始到首条字幕可用约37.0秒降到10.5秒。新旧首片长度不同，模型预热另计，未覆盖用户视频的真实标签页采音；不能把这组数字当作所有视频的固定延迟。首次加载模型、本机识别、网络和翻译响应仍需时间，2秒分片不代表2秒内出现中文。

暂停、跳转、换视频或同窗口切换标签页后需要重新点击开始。请求失败时停止采音，手动重新开启；已提交的模型调用可能继续完成，停止不会撤销已消耗的用量。分段、网络及翻译处理都会造成延迟，不能保证实时或完整转写；浏览器要求用户主动点击开始采音。默认识别额度是每小时900秒，可在设置页调整到3600秒，模型调用次数仍受单独额度限制；短分片可能增加识别调用次数。

## 隐私与限制

字幕及识别原文会发送到所选翻译服务；仅选择云端识别并开启音频捕获时，音频片段才发送到语音 API。本地识别只在内存处理音频，不保存音频片段。程序不上传完整视频。请检查所选服务的隐私与计费设置。字幕可用性、识别质量、网络和服务响应都会影响效果与延迟。

YouTube 优化模式支持桌面浏览器的普通 watch 视频，Shorts 和手机 App 未覆盖。其他网站使用通用 HTML5 字幕或网页 CC 兜底，不能保证所有播放器兼容。浏览器原生 `<video>` 全屏无法叠加 HTML 浮层，优先使用网站播放器的容器全屏。DRM / 付费站点、登录后课程、无字幕实时采音及真实语音 API 尚未全面验证；不承诺 Netflix、Udemy 等站点已适配。
