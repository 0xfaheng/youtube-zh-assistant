# 译幕 0.3.14：字幕用空格停顿

在 Chrome / Edge 扩展管理页重新加载译幕，确认版本 0.3.14，再刷新视频页面。无需重新配对。

中文字幕和原文会将逗号、句号、问号、感叹号、引号、括号、省略号等标点替换为空格，连续标点及重复空格合并为一个空格。例如“你好，世界。”显示为“你好 世界”。

为保留原意，小数点和英文单词内部撇号继续显示。仅处理扩展显示的字幕正文，原始字幕、送给翻译服务的文本和字幕时间保持原样；加载与错误提示仍使用正常标点。

颜色选择、拖拽位置、字号和背景设置继续保留。弹窗预览同样显示无停顿标点的文字。

验证：130 项自动测试通过；隔离 Chromium 模拟视频字幕，验证 YouTube / 通用 HTML5 播放器中两行字幕的显示、拖拽、颜色与刷新保存。未调用翻译模型。资料见 verification/subtitle-punctuation。
