# 使用与升级说明 · 0.3.10

1. 在 chrome://extensions 对已安装的“译幕”插件点击重新加载，确认 0.3.10，然后刷新视频页。当前安装目录仍是 E:\YouTube中文插件开发\outputs\youtube-zh-assistant\extension。保持同一目录时配对码和设置继续使用。
2. 其他网站点插件中的“在此网站启用”，确认所列具体网站和已知嵌入播放器授权；已有 Dailymotion/Khan 授权需补充确认新版播放器来源。先开启网站播放器字幕，再播放视频。
3. 弹窗可调整顶部/底部、距边缘 0–70%、字号 14–48px、背景浓度 0–100%，修改即时保存；恢复默认不会改变翻译开关。
4. 本轮 Khan Academy 公开嵌入样本已显示中文，Dailymotion 有成功记录但起播不稳定。edX、Udemy、Coursera 受登录或安全验证限制，暂不承诺课程字幕兼容。DOM 字幕有处理延迟和漏句可能，晚到译文带原句时间。
5. 当前翻译仍通过本机 Codex CLI 使用 ChatGPT 账号；本地 Qwen3-ASR 负责手动采音后的语音识别。账户/API 设置没有被这次升级更改。

完整安装包解压后运行 start.cmd；替换其他目录前先运行旧目录 stop.cmd。当前本机服务已更新到 0.3.10。测试详情见《五平台五轮测试报告-v0.3.10.md》，未验证的平台不视作已兼容。
