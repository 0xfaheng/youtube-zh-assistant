## 使用方式与外观

其他 HTTPS 视频网站使用“在此网站启用”，逐站授权后读取 HTML5 文字轨或网页 CC。优先验证 TED，Vimeo 暂列试验支持；开放 Shadow DOM 和常见 Video.js/Plyr 字幕已通过夹具验证，不能据此保证全部海外播放器兼容。字幕顶部/底部、距边缘 0–70%、字号 14–48px、背景浓度 0–100% 可实时调整并保存。图标采用“译幕”播放与字幕组合设计，提供 16/32/48/128/512px PNG 和 SVG。

## 配置与验证边界

本机服务已重启为 0.3.5，仍使用已有配对码。当前翻译后端为本机 Codex CLI 的 ChatGPT 账号路线，识别后端为本地 Qwen3-ASR；字幕和识别原文仍发送给账号模型翻译。配置请求 gpt-6-luna、high、Fast；实际 CLI 未给出可核对的模型/档位路由标识，不能据配置保证实际路由。账号用量和模型等待仍会影响延迟。

每轮通用浏览器测试使用独立 Edge Profile、真实 HTML5 媒体与模拟 HTTPS 页面数据。仅测试副本预授予指定来源，以自动化注入扩展；生产版仍保持逐站 optional 权限。直接撤销权限的逻辑通过自动测试，浏览器夹具覆盖授权复核拒绝后的清理；本轮没有在用户 Chrome 点击权限对话框。未读取用户日常浏览器 Profile 或 Cookie。

DRM/付费站点、登录后课程、浏览器原生 VIDEO 全屏、无字幕网页的完整采音识别翻译链路和真实云端语音 API 尚未全面验证。原生 VIDEO 全屏不能显示 HTML 浮层，使用网站的播放器容器全屏。DOM 兜底不能保证零漏句；迟到译文有时间标记，字幕间隙会清空旧结果。
