- 新增页面行为、扩展导航和自定义 API HTTP 集成测试，及可复用独立验证工具。浏览器验证脚本从 manifest 读取实际版本。

## 回退方式

- 旧版本不再留在正式交付目录，不能引用已经移出的旧包路径直接覆盖当前安装。
- Git 保留 `v0.4.7` 和本次发布前的完整历史，并在集成和发布后创建外部 bundle。需要回退时，从 `v0.4.7` 在新建的独立目录恢复源码，先验证再安排切换；不要在正式 main 执行 `reset --hard` 或覆盖标签。
- 切换前停止采音、核对 `/status` 待处理为 0，执行当前 `stop.ps1`；保留 `work/youtube-zh-assistant` 的配对码和运行配置，用核验后的旧源码启动服务，重载扩展并刷新页面。已有 API 配置结构兼容，旧版本的配置入口与连接测试行为会恢复。
- 本轮运行配置另有本机备份；Git bundle 不包含配对码、密钥、模型、安装包或未提交文件。主分支回撤产品改动优先新建 `git revert` 提交，保留审计历史。
