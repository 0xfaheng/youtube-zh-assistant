# v0.4.3 开发记录

## 版本信息

- 日期：2026-10-06，Asia/Shanghai。
- 前版本：0.4.2；新版本：0.4.3。
- 用户目标：解决字幕太长；用户明确选择中文最多 2 行、原文最多 2 行。
- 执行：ChatGPT 当前主代理独立实现并验收；没有调用子代理或 Astra，本轮没有新增 Opus 审校。当前主代理未收到可独立核验的具体模型标识。

## 改动内容

- `extension/semantic.js` 新增分页、两种语言的共用翻页时钟和布局缓存。每种语言分别最多两行，优先在句子、逗号和分号处分页；过长分句按词换行，单个超宽词按 Unicode 字素拆开。保留所有文字，不截断或用省略号代替，不缩小用户选择的字号。
- 按 Canvas 实际字宽、当前字体、播放器宽度规划页面，字体或尺寸变化时重新排版。中英文分别按自身字号测量，避免共用 Canvas 时使用错误字体。
- 保护普通英文单词、缩写、撇号、数值和常见技术符号，如 `50%`、`-5°C`、`3.14`、`3:30`、`C#`、`C++`。
- `extension/content.js`、`extension/generic.js` 两种播放器接入分页，完整语句及逐片字幕均生效。双语开启时中英文共用页序，页数较少的一侧保留当前段；关闭双语时只呈现中文。
- 字幕轨按原始组/字幕的开始与结束时间推进页面，播放暂停时页码保持，前后跳转定位对应页；不延长字幕时间，不改变翻译输入、内容或请求数量。实时字幕和采音按已有的显示窗口推进；无时间窗口的缓存字幕默认每页约 3 秒。
- 字幕区仍不显示处理或状态提示。翻译未完成时仍保留网站原生 CC，原生 CC 的排版由网站决定。
- 新增 8 项有意义的回归测试，覆盖全文保留、两行限制、单词/字素/符号、共享字体测量、时间边界、缓存、暂停和跳转。
- 同步安装元数据、扩展、本机服务、设置页及当前 README 版本为 0.4.3。更新变更日志和开发记录索引。

### 实际限制

没有逐词时间和双语对齐数据时，组内分页依据原时间窗口和文本排版估算，中英文部分页的分句对应也属于近似。短时间内特别密集的长字幕仍可能翻页较快；本版保留原结束时间，避免与下一句重叠。极窄播放器中的超长单词只有在单词自身超宽时才按字素折行。
