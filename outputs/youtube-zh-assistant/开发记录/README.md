# 版本开发记录

从 0.4.2 起，每次版本升级均新建独立开发记录，并保留历史记录、验证日志与安装包。升级日期按 Asia/Shanghai 记录。

| 版本 | 日期 | 开发内容 | 记录 |
| --- | --- | --- | --- |
| 0.4.7 | 2026-10-06 | 短片采音、识别与翻译并行、立即送译及延迟积压控制 | [v0.4.7](v0.4.7.md) |
| 0.4.6 | 2026-10-06 | 两行字幕保留句界与完整分句，修复行内语义拆分 | [v0.4.6](v0.4.6.md) |
| 0.4.5 | 2026-10-06 | 字幕启停统一控制原文与译文，初始化时序及本机连接修复 | [v0.4.5](v0.4.5.md) |
| 0.4.4 | 2026-10-06 | 版本显示统一，显式启用按钮及会话内启用策略 | [v0.4.4](v0.4.4.md) |
| 0.4.3 | 2026-10-06 | 中英文最多两行、长字幕自然分句分页与时间同步 | [v0.4.3](v0.4.3.md) |
| 0.4.2 | 2026-10-06 | 正式发布字幕提示修复；建立逐版本开发记录与打包检查 | [v0.4.2](v0.4.2.md) |

0.4.1 及更早版本已有的变更与验收证据仍保留在 [CHANGELOG](../CHANGELOG.md)、各版使用与升级说明、`verification/` 中，不补写未经核实的历史开发过程。

后续升级使用 [记录模板](模板.md)。版本记录必须包含实际改动、涉及文件、验证结果、交付文件和回退方式；填写完并通过验证后才能打包。当前项目打包入口为 `E:\YouTube中文插件开发\work\package-release.mjs`，该入口检查开发记录是否存在、是否完整、是否仍有未完成事项，以及插件/服务版本是否一致。
