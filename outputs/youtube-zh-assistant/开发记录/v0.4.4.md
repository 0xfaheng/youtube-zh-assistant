# v0.4.4 开发记录

## 版本信息

- 日期：2026-10-06，Asia/Shanghai；前版本 0.4.3，新版本 0.4.4。
- 用户目标：扩展管理页与插件工作区版本一致；增加明确的启用按钮，默认不启用。用户确认浏览器重启或扩展重新加载后需手动启用，本次浏览器会话内保持启用。
- 执行：ChatGPT 当前主代理独立实现与验收，没有调用子代理、Astra 或新增 Opus 审校。当前主代理没有可独立核验的具体模型标识。此前字幕提示的 Opus 5.5 与 ChatGPT 审校证据保留。

## 改动内容

- `extension/popup.html`、`popup.js`：修复面板写死 0.4.1 导致与扩展清单版本不一致的问题，改为 `chrome.runtime.getManifest().version`。新增“启用译幕／停用译幕”按钮和明确状态，初始化、保存期间禁用按钮，避免重复点击；保存失败保留原状态，旧轮询不会覆盖刚确认的用户操作。
- `extension/background.js`：默认关闭，手动启用标记存放 `chrome.storage.session`，附带当前版本。忽略旧版本持久化的 `enabled:true`；新会话或版本变化均关闭，同会话的后台 worker 恢复则保留用户选择。关闭后取消在途及排队翻译并关闭采音，拒绝未启用时的新字幕、翻译及采音请求。
- `extension/content.js`、`generic.js`：初始状态默认为关闭，等待后台确认。停用时不显示译幕，不自动开启或隐藏网站原生字幕。
- 配对、网站授权与外观设置不自动启用译幕。网站区用“授权”表述，采音入口在译幕停用时不可用。
- `web/app.js` 删除旧版硬编码重载提示；同步 `package.json`、扩展清单、服务、当前设置页和 README 到 0.4.4，保留历史版本说明。
- 新增 5 项回归测试，覆盖旧设置迁移、会话与 worker 恢复、未启用请求拒绝、停用取消、按钮失败与异步操作。`work/package-release.mjs` 增加面板动态读取版本的检查，防止再次出现界面版本不一致。
