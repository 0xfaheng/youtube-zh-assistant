本机字幕助手 · 预览版

看视频，读中文字幕。

连接浏览器插件，再选择字幕翻译和语音识别方式。

1. 连接扩展

双击 start.cmd 打开此页，再点“一键配对浏览器插件”。无需手动复制配对码。

浏览器插件尚未确认配对

若提示找不到插件，请在扩展管理页重新加载 0.4.7，并刷新本页。API 密钥在下面配置，不需要填入扩展。

2. 选择翻译方式

复用 CLI 的官方登录，使用 high 推理，字幕翻译共享 ChatGPT／Codex 用量。补齐本机代理后的单句样本约 11 秒完成；延迟可能变化，页面字幕会标记延迟译文。Fast 不可用时明确报错，可自行切回标准。

3. 第三方 API

等待连接本机服务

填写服务商提供的接口地址、API Key 和模型，即可用于字幕翻译。

填写服务商的基础地址，保留其要求的路径（如 /v1），不要附加 /chat/completions 或 /responses。远程服务使用 HTTPS；本机服务可用 HTTP。

第三方服务通常选择 Chat Completions，需支持 JSON 输出。模型 ID 以服务商文档为准。

连接后显示密钥配置状态，不回显密钥。

取消勾选后，新输入的密钥仅保留至服务退出。留空不会更改已有密钥的保存方式。

保存后启用 API 翻译；测试会发送一句文字，可能产生服务商费用。

API 翻译与云端语音目前共用这一个密钥；若使用不同服务，请确保密钥对两者均有效。本机语音识别无需密钥。

4. 语音识别与调用额度

本机识别不上传音频；识别出的文本仍会发送到上方选定的翻译服务。首次加载模型可能需要较长时间。

云端语音 API 会接收音频片段。使用上方「第三方 API」板块中的密钥；识别文本仍发送到上方选定的翻译服务。

控制调用额度

语音片段通常包含识别和翻译两次调用。达到上限就停止新请求；已有缓存仍可使用。
