# 译幕 0.3.13：字幕文字颜色

在 Chrome / Edge 扩展管理页重新加载译幕，确认版本 0.3.13，再刷新视频页面。无需重新配对。

点击译幕图标，在“字幕外观”中点击“中文颜色”或“原文颜色”右侧的色块，使用颜色选择器选色。两行可以分别设置不同颜色，预览立即更新，修改后自动保存并应用到已启用网页。

刷新、换视频、网页播放器全屏后仍保留颜色；颜色设置与原有外观一样在已启用网站间共用。调整颜色保留手动拖拽的位置。“恢复默认外观”将中文还原为白色、原文还原为浅灰色，并重置其他外观选项。

常驻“已同步”提示继续隐藏。加载、延迟和错误提示仍采用提示色。

验证：130 项自动测试通过；隔离 Chromium 使用模拟视频字幕验证 YouTube / 通用 HTML5 播放器的实际颜色、预览、刷新保存和恢复默认，并验证拖拽。未调用翻译模型。资料见 verification/subtitle-colors。
