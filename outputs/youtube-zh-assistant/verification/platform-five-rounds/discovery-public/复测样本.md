# 公网播放与英语字幕样本

2026-10-05，使用隔离 Edge Profile、Playwright、User HTTP_PROXY/HTTPS_PROXY 和 localhost bypass。只保存 DOM 观察、截图、按 domain/type/status 脱敏的网络响应日志；未调用翻译模型、未读取 token、未下载媒体。所有写入均在本目录。浏览器已关闭。

## Dailymotion 软字幕正例

URL：https://www.dailymotion.com/video/xaazv0o

播放器 iframe：`https://geo.dailymotion.com/player/xtv3w.html`（日志去除了 query）。标题 Breaking world news headlines 24/05/2026。字幕内容仅作为结构测试输入，未核验其新闻陈述。

实际播放：同一次运行 `currentTime 11.927465 → 20.925105 → 26.580648`、`duration 73.566667`、`readyState=4`、`paused=false`。

真实英语软字幕在 `.subtitles_placeholder`，`video.textTracks=[]`，不是烧录文字。20.925 秒与 26.581 秒保存了不同英语句子。

已实时核对祖先：`video#video → div.video_view → div.player.video_player → main → body → html.dmp_iframe`；字幕为 `div.subtitles_placeholder → div.player.video_player → main → body → html.dmp_iframe`。共同容器是 `.player.video_player`，`video.parentElement` 仅为 `.video_view`，不包含字幕。DOM scoped 查询应使用 `video.closest('.player.video_player')`。完整结构另存 `dm3-*-structure.json`，含共同容器 contains video/caption 的真值断言。

操作：打开页面后自动起播；在 iframe 中下部移动鼠标显示控件，然后 `frame.getByRole('button', {name:'字幕', exact:true}).click()`。这是字幕直接开关，已实际正常点击成功；等待数秒后读取 `.subtitles_placeholder`。字幕偏好会保存在隔离 Profile 中，已有字幕时不要再次点击关闭。不能把某一个空白间隙判定为无字幕。本次未确认语言选择菜单，`菜单` 按钮点击超时。

主要证据：
- `dm3-2026-10-05T03-00-43-134Z-initial.json/png`
- `dm3-2026-10-05T03-00-43-134Z-cc-menu.json/png`（正常开启后，20.925 秒有 DOM 字幕；文件名不代表语言菜单存在）
- `dm3-2026-10-05T03-00-43-134Z-settings.json/png`（26.581 秒字幕继续改变；settings 点击超时，标签不代表菜单成功打开）
- `dm3-2026-10-05T02-59-47-861Z-initial.json/png`（重开后偏好仍开启，12.308 秒有字幕）

## Khan Academy 软字幕正例（内嵌 YouTube）

URL：https://www.khanacademy.org/science/ms-biology/x0c5bb03129646fd6%3Acells-and-organisms/x0c5bb03129646fd6%3Acells-organisms/v/ms-cells-and-organisms

播放器 iframe origin：`https://www.youtube-nocookie.com`；path：`/embed/Uiqro5TUyLA/`。这是内嵌 YouTube，不是独立 Khan 原生播放器。

实际播放：同一次运行 `currentTime 14.071935 → 20.216695 → 32.332891`、`duration 236.701`、`readyState=4`、`paused=false`。默认英语字幕已开启，`.ytp-caption-segment` 分别显示不同句子。`video.textTracks=[]`。

正常起播步骤（父页面）：
1. 如有 Cookie 框，点击 `getByRole('button', {name:'Strictly Necessary Only', exact:true})`。
2. 如有捐赠大横幅，点击 `getByRole('button', {name:'close', exact:true})`。
3. 可关闭 `Close Sign Up Banner`；`Dismiss banner.` 是教师提示条。
4. 点击父页面的 `getByRole('button', {name:'Play video', exact:true})`，不是 iframe 初始 Play video 按钮。
5. 进入 youtube-nocookie.com iframe 读取 `.ytp-caption-segment`。应等待不同字幕文本和 currentTime 推进。

限制：iframe DOM 确有 `Subtitles/CC turned on` 按钮与默认已开启字幕，但本次正常点击该 iframe CC 按钮多次超时，未用 force 或脚本改字幕状态。因此只确认默认英语字幕实际出现、持续变化，不声称完成 CC 关闭/开启验收。截图在部分阶段会受到父页面内部滚动区裁剪，以 JSON 的字幕 DOM/播放推进证据为准。

主要证据：`khan-2026-10-05T03-00-14-342Z-{playing,cc-off,cc-on}.json/png`。`cc-off`/`cc-on` 是尝试操作的阶段标签，实际 CC 点击超时且字幕一直保持开启，不能按文件名推断状态。较早的 `khan-playing.json` 为未成功起播阶段，不要作为正例。

汇总：`verified-observations.json`，仅汇总保存的 DOM 观察，不包含媒体 URL query。
