## 回退与恢复

- 撤销本轮某项开发基础设施改动时，在干净工作区识别对应提交，使用 git revert 保存撤销记录，并复查发布入口与规则是否匹配；不删除 .git，不移动 v0.4.7 标签，不覆盖旧包。
- 查看原产品基线可在独立 detached worktree 检出 v0.4.7；正式运行回退仍按各版开发记录执行，保留配对码和配置。
- 恢复整个已提交仓库：clone 已校验 bundle 到新目录，再执行 git fsck --full；运行配置和安装包另行恢复，不能覆盖现有项目目录。
